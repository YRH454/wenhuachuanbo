# 一物见山东

一个探索山东十六市地域文化的交互式网页原型。首页通过文化插画组成的地图进入城市，再向下阅读对应的文化专题、手艺与人物及本城四物。

## 本地运行

需要 Python 3，无需安装第三方 Python 包：

```bash
python server.py
```

在浏览器访问 <http://127.0.0.1:4199/>。如端口已被占用，可运行 `python server.py --port 4200`，然后访问对应端口。

## 当前范围

- 十六市地图及城市背景；地图画作可切换水墨与工艺融合两种版本。
- 十六城文化专题、来源链接、人物与四物，以及从城市画面继续向下阅读的页面结构。
- 动态文化向导“小齐”：支持移动、暂停、收起、换边，并可进入当前城市正文。
- 页面内的问答是编辑整理的固定内容；小齐当前只有欢迎面板和本地导航，**尚未接入 AI 模型或对话服务**。
- 首页与城市之间的动画和基本响应式布局。

`dist/` 中包含页面源代码及运行所需的图片和资料记录。用于生产与验收的绝对本机路径已经在本仓库副本中移除；原始文件及完整记录仍保留在本地工作区。素材较多，首次克隆可能需要一些时间。

## 测试

```bash
node --test test_navigation.mjs test_backgrounds.mjs test_zibo_guide.mjs test_competition_copy.mjs test_xiaoqi_guide.mjs test_xiaoqi_motion.mjs test_distribution.mjs
```

## 使用说明

地域背景及地图画作为 AI 创意插画，不代表实景照片、特定馆藏或历史复原。文化信息与链接需要在后续持续核对；地图的行政边界、审图要求以及各素材公开使用条件尚未最终确认，本仓库是开发原型，不应直接视为已获公开发布许可的成品。

公开仓库版本不包含标记为仅供内部参考、未获公开复用许可的人物候选照片；原图仍保留在本地工作区。普通浏览页面原本也不会展示这些候选图，获授权后再另行接入。

请勿将 API 密钥、访问令牌或本机私密文件提交到仓库。未来接入模型时，应由服务端使用环境变量读取密钥。
