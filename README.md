# 一物见山东

一个探索山东十六市地域文化的交互式网页原型。首页通过文化插画组成的地图进入城市，再向下阅读对应的文化专题、手艺与人物及本城四物。

## 本地运行

需要 Python 3，无需安装第三方 Python 包：

```bash
python server.py
```

在浏览器访问 <http://127.0.0.1:4199/>。如端口已被占用，可运行 `python server.py --port 4200`，然后访问对应端口。

## 当前范围

- 十六市地图及城市背景；地图画作可切换水墨与工艺融合两种版本。
- 十六城文化专题、来源链接、人物与四物，以及从城市画面继续向下阅读的页面结构。
- 动态文化向导“小齐”：支持移动、暂停、收起、换边，并可进入当前城市正文。
- 地图、城市、人物与文化载体及博物馆共用小齐的本机模型服务；自动讲解可关闭，语音需主动开启，也可围绕当前场景提问。城市正文原有的固定问答仍保留。展品和城市资料仍在逐件核验，不应视为完整知识库。
- 首页与城市之间的动画和基本响应式布局。

`dist/` 中包含页面源代码和可公开分享的部分图片。博物馆中使用许可待核的图片及其缩略图未纳入公开仓库，原文件仍留在本机；因此克隆后部分展品图片和图片墙会暂时缺图。详见 [博物馆公开素材说明](dist/museum/PUBLIC-ASSETS.md)。

全站模型预览的启动方法见 [小齐组件说明](dist/museum-assistant/README.md)；静态服务 `server.py` 不提供模型接口。模型密钥只应通过本机安全输入或环境变量提供，不应上传到 GitHub。当前模型服务只供本地预览，正式部署前的条件见 [部署准备](DEPLOYMENT.md)。

## 使用说明

地域背景及地图画作为 AI 创意插画，不代表实景照片、特定馆藏或历史复原。文化信息与链接需要在后续持续核对；地图的行政边界、审图要求以及各素材公开使用条件尚未最终确认，本仓库是开发原型，不应直接视为已获公开发布许可的成品。

公开仓库版本不包含标记为仅供内部参考、未获公开复用许可的人物候选照片，也不包含博物馆权利待核的图片；原图仍保留在本地工作区。获授权后再另行接入。

请勿将 API 密钥、访问令牌或本机私密文件提交到仓库。
